# Elysium Translations

Game translation projects by **Siegfried776**: new English translations and translation revisions, mostly of Asian games. Each project has its own folder with a README, install instructions, a changelog and any tools.

## Players

Download the zip for your game from the [Releases](../../releases) page and follow the install steps in that project's README. You need to own the game. The patches contain no game files.
