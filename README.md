## About

I'm Siegfried. I've been learning Japanese roughly since 2018, and I've studied linguistics and phonology in my spare time. I've spent thousands of hours learning and consuming media purely in Japanese. I've worked on projects before: manga, visual novels and videogames, but most were done as a hobby and went unpublished. I love Asian games and most of them either go without a translation or get one that doesn't do them justice. I've decided to use Claude to fix that, for Chinese and possibly other Asian language games, as I have no knowledge of those languages. I do not intend to make a statement about AI/MTL, but I choose to be transparent about AI usage in these projects. These projects will range from bug fixes, to preservation work on older PC games (getting them to run on modern Windows) and full translation or retranslation patches.

This repository will serve to collect these projects and share them with the public. I work very hard to set the voice and style, make the naming and terminology calls, and playtest and report bugs.

## Players

Download the zip for your game from the [Releases](../../releases) page and follow the install steps in that project's README. You need to own the game. The patches contain no game files.
