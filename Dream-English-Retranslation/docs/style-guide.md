# Style guide

Conventions used throughout the retranslation. Follow these when editing `translation/en.json`.

## Voice

- **Goal:** natural English that reads like a visual novel written in English, not a translation of one.
- **Narration:** present tense ("I run with Chen Xiu to the great door…").
- **Diaries, notes, letters, journal entries:** past tense, in the writer's own voice.
- **Ellipses:** sparingly. Use them only for real trailing off or hesitation; never as default punctuation. A line that is only silence is written `......`, as in the original.
- **Item pickups:** `Obtained: <item>.`

## Formatting

- `/n` is the game's line break. Keep existing ones; add new ones only where a line would overflow the text box.
- Keep `<color=#...>…</color>` tags exactly as they are.
- Numbers that matter to puzzles must stay numbers (e.g. `5 Button`).
